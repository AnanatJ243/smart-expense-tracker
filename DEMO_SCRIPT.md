# Video Demonstration Script

Record a 3–5 minute screen capture.

1. Run `pip install -r requirements.txt`, then `python -m src.main`.
2. Add an expense and show it in View/Filter.
3. Update the expense, then delete a test expense.
4. Filter by date/category/payment mode and search a description keyword.
5. Set a monthly category budget. Add spending and open Budget Status to show OK, OVER 80%, and OVER 100% states.
6. Generate the monthly report and show total spending, average daily spending, and highest category.
7. Export CSV and PDF and open the generated files.
8. Generate the pie, daily-trend, and budget-vs-actual charts.
9. Exit and relaunch the program; show that SQLite preserved the records.
10. Create a JSON backup, make a test change, restore the backup, and show recovery.

Suggested closing narration:
“This Smart Expense Tracker demonstrates object-oriented Python, validation and exception handling, SQLite data persistence, Pandas analytics, Matplotlib and Seaborn visualization, CSV/PDF reporting, and modular application architecture.”
